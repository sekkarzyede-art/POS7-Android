# POS7 R301 — مرحلة الاستعادة التشغيلية الآمنة واختبار النقل الخادمي

**التاريخ:** 22 نوفمبر 2026. 

## نتائج مؤكدة

- **R299:** مدقق النسخة الاحتياطية المحلية ومحرك الاستعادة إلى المفتاح الأصلي `POS7_TRIAL188_CLEAN` موجودان في Android الموحد المرحلي؛ فحص البيانات ثم الاستعادة بالرجوع عند الفشل، ومنع استبدال سجلات جهاز نشط.
- فحوص R299 JavaScript نجحت، وفحص ترجمة Android نجح على GitHub: https://github.com/sekkarzyede-art/POS7-Android/actions/runs/44957453973
- **R300:** 16 حالة اختبار تشفير P-256 ناجحة، والتحقق من توقيع Java من خدمة WebCrypto ناجح. اختُبر منح تحدٍّ عبر `service_role` وتوثيق الدور ومعاملة النقل للناشر والجرد في PostgreSQL 16 معزول. فحص TypeScript Edge ناجح: https://github.com/sekkarzyede-art/POS7-Android/actions/runs/44958406992
- لم تُنشأ أي معاملة استبدال في سحابتي الإنتاج، ولم تُعدّل دوال الأجهزة المثبتة.

## R301 — APK تشخيصي آمن منفصل

- المصدر مبني من R299 لكن `applicationId` أصبح `com.sokkarzeyedeh.pos7.recoverytest` بدل تطبيق المتجر `com.sokkarzeyedeh.pos7`.
- لا يمتلك تصريح INTERNET ويغلق WebView network loads من Android.
- يبدأ بشاشة اختيار المتجر وفحص نسخة JSON واستعادتها محليًا فقط.
- الواجهتان الأصليتان تحملان شريطًا أحمر دائمًا «نسخة فحص تجريبية — دون إنترنت» مع منع أزرار عمليات البيع والشراء؛ الغرض التأكد من استعادة البيانات وعرضها فقط، وليس العمل اليومي.
- يُوقّع APK التجريبي بمفتاح Debug مختلف. لا يمكن استخدامه لتحديث الإصدار المثبت الحالي ولا يمثل توقيع النشر النهائي.

## لم يكتمل بعد

1. إثبات تجانس جميع السجلات والفواتير المعلقة بين النسخة القديمة وأحدث نسخة سحابية قبل الانتقال. **تاريخ ملف النسخة وحده غير كافٍ**.
2. تطبيق ونشر Supabase Edge verifier فعليًا ثم ربطه مع Android Keystore وخطوة استعادة محلية مكتملة.
3. نقل صلاحية الناشر والجرد فعليًا عبر الخدمة مع إيقاف القديم من النشر، ومنع مسار `pos7_owner_rebind_device` القديم بعد الاستبدال، دون تعطيل نسخ R213/R215 المثبتة.
4. التحقق على أجهزة Android من القراءة الصحيحة للبيانات بين WebView، ثم إثبات الشهادة الأصلية وversionCode قبل ترقية APK الموحد.

## قرار الإصدار

**R301 اختبار مستقل فقط. المشروع الموحد التشغيلي ما زال غير جاهز للتثبيت على المتجرين.**

لم يتم تغيير `main` أو الإنتاج أو أجهزة المتجرين. لا يجوز استخدام النسخة التجريبية للبيع أو الشراء.
